# Judge Q&A Prep - Owner: Person 5

Draft answers are **starting points**. Replace with facts from our tests. If we do not know, say "we did not test that" - that is a good answer.

| Topic | Likely question | Honest answer direction |
|---|---|---|
| Originality | "What is new here?" | |
| Fit to brief | "How does this answer the challenge?" | Point to the brief's wording and our requirements |
| Reliability | "How reliable is it?" | Small sample, provisional targets; list what we did and did not test |
| Cost | "What would it cost?" | Only a parts list; no unmeasured savings |
| Certification | "Does it meet standards?" | No, it is a proof of concept |
| Manufacturing | "Could this be manufactured?" | Printed prototype; other processes not validated |
| AI use | "How do you know the AI was right?" | Show the log: errors caught, measurements, tests that overruled the AI |
| Failure | "What failed?" | Show the v1 failure and the v2 fix with numbers |
| Next steps | "What would you do next?" | |
| Team | "Who did what?" | README team table; each person speaks to their part |
